# Loomstead Atelier — garment quality annotations

Human quality annotations for the Loomstead Atelier garment collection.

This repository distributes **annotation scores only**. Image data, catalogue metadata and the
original records are not redistributed here. The underlying catalogue is the *Siftloom Garment
Raw* corpus, published separately by the Siftloom data team.

## Files

- `annotations/quality_scores.csv` — per-item aesthetic scores (12,400 rows in the production export,
  40 rows in this public sample)
